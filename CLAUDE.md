# CLAUDE.md

Правила работы над Локсо для AI-агентов.

Команды, код-стайл и запуск тестов — в [AGENTS.md](AGENTS.md). Здесь только то,
чего там нет.

## Проект

Локсо — самостоятельный продукт: система управления проектами и задачами.
Код происходит из Plane CE, но связи с исходным проектом нет: свои изменения
никуда не отдаём, чужие не подтягиваем. От происхождения осталось одно
обязательство — атрибуция AGPL в `README.md`.

Стек: Django REST API (`apps/api`) плюс фронтенды на React Router и Vite
(`apps/web`, `apps/admin`, `apps/space`, `apps/live`), монорепозиторий pnpm.

Текущие приоритеты и фазы работ: `docs-lokso/plan-rabot-lokso.md`.

## Карта репозитория

Архитектура модульная — новое кладётся по существующим паттернам:

| Что добавляешь      | Куда                                                                                                |
| ------------------- | --------------------------------------------------------------------------------------------------- |
| OAuth-провайдер     | `apps/api/plane/authentication/provider/oauth/` — файл на провайдера, образцы `yandex.py` и `vk.py` |
| Состояние фронтенда | MobX-сторы, `packages/shared-state`                                                                 |
| Общий UI-компонент  | `packages/ui`, с историей в Storybook                                                               |
| Фоновая задача      | `apps/api/plane/bgtasks/`                                                                           |
| Строки интерфейса   | `packages/i18n/src/locales` — 19 локалей, см. скилл `translate`                                     |

Оговорки:

- **Распухшие файлы.** `apps/api/plane/api/views/issue.py` (2589 строк),
  `apps/web/core/store/issue/helpers/base-issues.store.ts` (1979),
  `apps/api/plane/bgtasks/issue_activities_task.py` (1604). Читай и правь
  точечно, не переписывай целиком.
- **Пакеты `@plane/*` не переименовываем.** Отдельный крупный рефактор,
  требует отдельного решения.
- **Биллинг-UI спящий.** Код в `apps/web/core/components/workspace/billing/`
  есть, платных аккаунтов нет. Не вырезать и не подключать без решения.

## Делегирование

Claude делает сам и делегирует сабагентам. Но часть действий выполняет только
Артём — их не автоматизировать, а явно попросить и дождаться подтверждения:

- покупка доменов, аренда серверов, оплата сервисов;
- регистрация приложений в кабинетах Яндекс ID и VK ID, получение API-ключей;
- юрлицо, товарный знак, регистрация оператором ПДн в РКН.

## Персональные данные (152-ФЗ)

- Не логировать PII (email, ФИО, IP) сверх необходимого для работы функции.
- Телеметрия и продуктовая аналитика — только self-hosted и с согласия
  пользователя.
- Данные пользователей хранятся в российской инфраструктуре.

## Секреты

Ключи Яндекс ID, VK ID, YandexGPT и GigaChat живут только в `.env` — файл под
`.gitignore`. Никогда в коммит, в `*.env.example` и в логи.

Нужен новый ключ — запросить у Артёма. Не подставлять заглушку: о ней забудут.

## Локальная разработка

Полная инструкция — [ЛОКАЛЬНАЯ-РАЗРАБОТКА.md](ЛОКАЛЬНАЯ-РАЗРАБОТКА.md).
