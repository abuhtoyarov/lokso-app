# Локсо (Lokso)

**Локсо (Lokso)** — открытый таск-трекер, форк Plane v1.3.1 (AGPL-3.0). Исходный проект: https://github.com/makeplane/plane

Локсо — инструмент управления проектами: рабочие элементы (задачи), циклы, модули, страницы и аналитика — без хаоса в самом инструменте.

Сайт: https://lokso.ru • Документация: https://lokso.ru/docs

## Возможности

- **Рабочие элементы** — создание и ведение задач в редакторе с богатым форматированием и загрузкой файлов, свойства, подзадачи, ссылки.
- **Циклы** — спринты с burn-down-графиками и отслеживанием прогресса.
- **Модули** — деление крупных проектов на управляемые части.
- **Представления (Views)** — настраиваемые фильтры, сохранение и совместный доступ.
- **Страницы** — заметки и документация в контексте проекта.
- **Аналитика** — данные по проектам в реальном времени.

## Установка (self-hosted)

Локсо разворачивается самостоятельно (Docker / Kubernetes). См. каталог `deployments/` и документацию по самостоятельному развёртыванию.
